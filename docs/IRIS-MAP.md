## Why the codes are blank

I don't have the verified IRIS code for this yet. The exact field codes have not been transcribed with verified provenance. Use this worksheet for review, not as a filing instruction; check the tax-year-specific screen in IRIS with your practitioner.

A wrong field code does not show a wrong screen. It files a figure in the wrong box, which is a misdeclaration carrying the customer’s name — so no code here is ever written from memory, from a blog post, or from another tool’s output. The sections of law are different: those come from `docs/TAX-RULES.md`, which was checked against the Ordinance, and they are safe to rely on.

## How to transcribe one

1. Sign in to IRIS and **start, without submitting**, a return of income for the right tax year and taxpayer type (individual, non-salaried business).
2. Navigate to the path in the table below.
3. Copy the field’s code and its label **exactly as IRIS prints them**, including any odd capitalisation or spacing.
4. In `src/iris.ts`, set `code`, `irisLabel`, `verified:true`, and put your source (`IRIS screen` or `FBR return form SRO …`), `checkedOn` and `checkedBy`.
5. Run `npm run iris` and commit the source and the regenerated worksheet together.

Leave anything you could not find unverified. A blank is honest; a guess is not. Two fields are marked optional because a return may not show them at all: the s.4AB surcharge appears only above the threshold, and the s.154B row only from TY2027.
